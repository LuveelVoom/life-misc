Each line is one branch, drawn from the height it started at to the height it reached. Vertical joins are partitions: a branch that hits the memory cap is split into 4 children that restart one level higher. Hover for details; click to highlight a branch in every chart and the table.

What the solver was doing over time

Extend runs and partition builds on one clock (UTC). The run is sequential, so gaps between bars are idle time. Hatched runs resumed after an interruption; the resume time isn't logged, so they are drawn from the interruption. Triangles mark manager pauses.

Height over time

Each run is a segment from (start time, start height) to (end time, height reached). Only the endpoints are logged, so the straight line between them is an assumption, not measured progress.
